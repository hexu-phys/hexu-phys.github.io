Estimating an exponent from a system-size series

Method note · 2025 · 6 min read

When a quantity is measured on a series of finite systems, the estimate of an exponent depends on which sizes are included and how the fit is weighted. This note walks through a practical procedure: choose the size range from a residual analysis rather than by eye, treat the smallest sizes as correction terms instead of data, and report a confidence interval obtained by resampling the underlying measurements rather than the fitted points.

  • Convert each run into a measurement with an error bar before fitting.
  • Fit with an explicit correction term; compare against the uncorrected fit.
  • Report the systematic spread across fit windows alongside the statistical error.
Separating statistical from systematic uncertainty

Method note · 2024 · 5 min read

Error bars that combine everything into one number hide the decisions that produced them. I keep the two contributions in separate columns through the whole pipeline, and only combine them at the final table, so that a change in one source does not silently rescale the other.

  • Statistical: bootstrap over independent samples or trajectories.
  • Systematic: vary analysis choices one at a time and record the spread.
  • Report both, plus the number of independent samples behind each estimate.
A minimal reproducibility checklist for numerical projects

Practice note · 2023 · 4 min read

A short checklist I run before calling an analysis finished. It is deliberately boring: the goal is that someone else, or my future self, can regenerate every figure in the time it takes to make coffee.

  • One documented entry point; no manual intermediate steps.
  • Configuration in a file, not in the shell history.
  • Every figure produced by a script and listed in a figure manifest.
  • Environment pinned, with versions recorded next to the run log.
  • Raw output treated as read-only; derived quantities written to a separate directory.
